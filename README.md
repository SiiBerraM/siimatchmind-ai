# SiiMatchMind AI — الإصدار 0.3

تطبيق ويب عربي (RTL) متعدد اللغات لتحليل وتوقع مباريات كرة القدم، يعمل على هاتف أندرويد (Termux + Chrome) ويُثبَّت كـ PWA.
اللغات: العربية، English، Français، Español، Türkçe (ترجمات آلية من إعدادي تحتاج مراجعة ناطق أصلي).

> **البيانات الافتراضية تجريبية** (فرق خيالية ونتائج مولَّدة بالحاسوب) إلى أن تستورد بيانات حقيقية. التوقعات تقديرات إحصائية وليست ضمانًا.

## حالة كل ميزة (بصدق)
| الميزة | الحالة |
|---|---|
| محرك بواسون + اختبار رجعي (Brier/LogLoss/معايرة) | منفَّذ ومُختبَر (73 اختبار وحدة) |
| منطق الـ API (تحقق/أخطاء/صلاحيات/حسابات/مفضلة/إدارة) | منفَّذ ومُختبَر عبر **طلبات HTTP حقيقية** على `server_lite.py` |
| خادم FastAPI (`main.py`) | مُجرَّب على هاتف المستخدم (طلبات HTTP ناجحة) |
| قاعدة بيانات SQLite (فرق، مباريات، إحصائيات، مستخدمون، توقعات) | منفَّذ ومُختبَر |
| حسابات (PBKDF2 + جلسات مُجزَّأة + قفل بعد 5 محاولات) | منفَّذ ومُختبَر، مع مزامنة المفضلة والسجل |
| لوحة الإدارة `/admin.html` + مراقبة جودة حية | منفَّذ ومُختبَر في المتصفح |
| تحديث تلقائي + نسخ احتياطي | منفَّذ ومُختبَر (خادم محاكاة) |
| استيراد API-Football | مُجرَّب على الخدمة الحقيقية من هاتف المستخدم (مباريات + إحصائيات)؛ الإصابات والتشكيلات لم تُجرَّب حقيقيًا |
| استيراد football-data.org | منفَّذ ومُختبَر **ضد خادم محاكاة فقط**؛ لم يُجرَّب بعد على الخدمة الحقيقية |
| الإصابات والتشكيلات | تُعرض للاطلاع فقط؛ **لا تدخل في حساب الاحتمالات** (لا يوجد أثر مُعايَر لها) |
| الترجمة | 5 لغات، واتجاه RTL/LTR تلقائي، وإضافة لغة = ملف JSON واحد |
| ملفات النشر (Dockerfile, render.yaml) | مكتوبة، **لم تُجرَّب** (تحتاج حساب استضافة) |

## التشغيل على أندرويد (Termux من F-Droid)
```bash
termux-setup-storage
pkg update -y && pkg upgrade -y
pkg install -y python unzip python-pydantic
pip install fastapi uvicorn
cp ~/storage/downloads/SiiMatchMind.zip ~/ && cd ~ && unzip -o SiiMatchMind.zip
cd ~/SiiMatchMind/backend && python -W ignore -m unittest discover -s tests   # يجب أن ترى OK
```
**شغّل الخادم** (اختر واحدًا):
```bash
export ADMIN_TOKEN="رمز-طويل-من-اختيارك"
sh ~/SiiMatchMind/run.sh          # FastAPI
sh ~/SiiMatchMind/run.sh lite     # بديل بدون FastAPI (إن تعذّر تثبيته)
```
ثم افتح Chrome على `http://127.0.0.1:8000`. **اختبار الخادم:** من جلسة Termux ثانية:
```bash
cd ~/SiiMatchMind/backend && ADMIN_TOKEN="نفس-الرمز" python smoke_test.py
```
يجب أن ترى `✔ كل شيء سليم`. إن فشل شيء أرسل لي المخرجات.
لوحة الإدارة: `http://127.0.0.1:8000/admin.html` (برمز ADMIN_TOKEN).

## ربط بيانات حقيقية (مجاني) — مصدران، اختر واحدًا لكل قاعدة بيانات
| | football-data.org | API-Football |
|---|---|---|
| الخطة المجانية | 12 بطولة كبرى، **الموسم الحالي**، 10 طلبات/دقيقة، نتائج متأخرة قليلًا | 100 طلب/يوم، **مواسم 2022–2024 فقط** |
| مباريات اليوم والقادمة | **نعم** | **لا** (مواسم قديمة فقط) |
| إحصائيات (استحواذ/تسديدات/ركنيات) | لا | نعم (طلب لكل مباراة) |
| المفتاح | `FOOTBALL_DATA_KEY` | `API_FOOTBALL_KEY` |

يمكن الجمع بين المصدرين في قاعدة واحدة (لكل بطولة مصدرها ونموذجها). `--replace` يمسح كل البيانات صراحةً (لا يمس الحسابات والمفضلة).
```bash
# football-data.org: سجّل في football-data.org وستصلك رسالة بالمفتاح
export FOOTBALL_DATA_KEY="مفتاحك"
python importer.py --source football-data --competition PL,PD,BL1,SA,FL1     # PL=الإنجليزي، PD=الإسباني، BL1=الألماني، SA=الإيطالي، FL1=الفرنسي (~35 ثانية)

# API-Football
export API_FOOTBALL_KEY="مفتاحك"
python importer.py --league 39 --season 2023
python importer.py --league 39 --season 2023 --stats-last 30       # + إحصائيات آخر 30 مباراة
```
أعد تشغيل الخادم بعد الاستيراد. لا تشارك مفتاحك في لقطات شاشة أو محادثات.

## واجهة احترافية (الإصدار 0.8)
شعارات الفرق (من المزوّد، أو حرف بديل إن غابت)، جدول ترتيب محسوب من النتائج، ترتيب أبجدي للبطولات بأسماء مترجمة، متابعة الفرق وقسم «مباريات فرقك»، مشاركة التحليل، وضع فاتح/داكن، عرض نتيجة المباراة أو موعدها في صفحة التحليل، «آخر تحديث»، وهياكل تحميل. حقوق الشعارات لأصحابها ولشروط المزوّد.

## جاهزية النشر
- **حذف الحساب** من التطبيق (المحفوظات ← حذف حسابي)، مطلوب في بلاي ستور.
- **سياسة الخصوصية والشروط:** `frontend/privacy.html` و`terms.html` قالبان أوليان بالعربية والإنجليزية. **غيّر `CONTACT_EMAIL` ببريدك قبل النشر** وراجعهما بنفسك أو مع مختص (لست محاميًا).
- **حدّ الطلبات** لكل عنوان IP: 300 في الدقيقة عامًا، و10 محاولات في الدقيقة لتسجيل/دخول/حذف.
- **ترويسات أمان** (nosniff، no-referrer، منع التضمين) وملف تثبيت (manifest) بأيقونة قابلة للقناع.
- ما زال ينقص النشر الدائم: استضافة بعنوان https ثابت، ثم ملف APK عبر PWABuilder، وحساب مطوّر لبلاي ستور.

**بريد التواصل في صفحتي القانون:** اضبطه مرة واحدة بمتغير البيئة `SMM_CONTACT_EMAIL` (فلا يُمحى عند التحديث).

## الدوريات العربية بالموسم الحالي (Highlightly، مجاني)
خطة BASIC المجانية: 100 طلب/يوم، وقد أثبت اختبار حقيقي أن الدوري المصري متاح فيها بموسم 2026. الاستيراد الكامل لدوري = نحو 4 طلبات.
```bash
export HIGHLIGHTLY_KEY="مفتاحك"
python importer.py --source highlightly --hl-find Egypt          # يعرض أرقام الدوريات (طلب واحد)
python importer.py --source highlightly --hl-league 199067 --season 2026
```
**إحصائيات وتشكيلات:** `python importer.py --source highlightly --hl-stats 8` (استحواذ وتسديدات وركنيات لآخر 8 مباريات منتهية لكل دوري، طلب لكل مباراة) و`--hl-lineups` (تشكيلات مباريات اليوم وغدًا، تظهر قبل المباراة بقليل). تعمل تلقائيًا مع التحديث (`SMM_HL_EXTRAS=0` لإيقافها).
التحديث التلقائي لدوريات Highlightly كل 12 ساعة (`SMM_HL_REFRESH_HOURS`) ويتوقف قبل نفاد الحصة اليومية. تنبيه: وثائقهم تقول إن الخطة المجانية قد تُخفي بعض النتائج؛ قارن عدد المباريات المستوردة بما تتوقعه. ولم أجد نصًا عن الاستخدام التجاري، فراجع شروطهم قبل النشر.

**تنظيف:** إن استوردتَ دوريًا أرشيفيًا (API-Football) ثم نسخته الحالية (Highlightly) بنفس الاسم، تُخفى الأرشيفية تلقائيًا من قائمة البطولات. ولحذفها نهائيًا: `python importer.py --drop-league 233,307` (بالرموز الظاهرة في `/api/leagues`).

## الدوريات العربية أرشيفًا (API-Football)
football-data.org المجاني لا يضمها. المصدر المجاني الوحيد القادر هو API-Football، لكن خطته المجانية تتيح **مواسم 2022–2024 فقط**، فتُعرض هذه الدوريات كـ«أرشيف»: تحليل أي فريقين بنتائج آخر موسم متاح، بلا مباريات اليوم والقادمة.
```bash
export API_FOOTBALL_KEY="مفتاحك"
cd ~/SiiMatchMind/backend
python importer.py --find egypt         # يعرض رقم الدوري (طلب واحد). كرّره مع: saudi و morocco و emirates و qatar
python importer.py --league 233 --season 2024     # مثال: الدوري المصري (233 مؤكَّد من مصدر عام؛ تحقق من البقية بـ --find)
```
أرقام يُرجَّح أنها صحيحة (تحقق منها بـ `--find` قبل الاستيراد): السعودي 307، المغربي 200، الإماراتي 301، القطري 305. كل استيراد يستهلك طلبًا واحدًا من حصتك اليومية (100). المصدران يعيشان في قاعدة واحدة لأن النموذج منفصل لكل بطولة.

## بطولات متعددة
يدعم التطبيق عدة بطولات في قاعدة واحدة: محدّد البطولة في أعلى الشاشة يرشّح المباريات والفرق والجودة، وكل بطولة تُحلَّل بنموذجها الخاص (لا تُقارَن فرق من بطولتين). التحديث التلقائي يجدّد كل البطولات المستوردة. استخدم البطولات المحلية فقط (PL, ELC, BL1, SA, PD, FL1, DED, PPL, BSA) ولا تستورد CL أو WC أو EC لأن فرقها تتداخل مع بطولاتها.

## التحديث التلقائي والنسخ الاحتياطي
- **تحديث تلقائي:** إذا كان `FOOTBALL_DATA_KEY` مضبوطًا والبيانات مستوردة من football-data.org، يحدّث الخادم النتائج والجداول كل 6 ساعات (طلب واحد). غيّر الفاصل بـ `SMM_REFRESH_HOURS` (0 = إيقاف). أخطاؤه تظهر في لوحة الإدارة ولا توقف الخادم. API-Football لا يُحدَّث تلقائيًا (حصته محدودة).
- **نسخة احتياطية:** `python backup.py` من مجلد backend، تُحفظ في `data/backups/` (آخر 7 نسخ). الاستعادة: أوقف الخادم وانسخ الملف فوق `data/smm.db`.
- **إبقاء الخادم حيًا على أندرويد:** اسحب إشعار Termux واضغط **Acquire wakelock**، وأوقف توفير البطارية لتطبيق Termux.
- **تثبيت كتطبيق:** افتح `http://127.0.0.1:8000` في Chrome ثم القائمة ⋮ ثم **Add to Home screen / Install app**.

## إضافة لغة
انسخ `frontend/locales/en.json` إلى `xx.json`، ترجم القيم (احتفظ بالمتغيرات مثل `{team}`)، وأضف سطرًا في `locales/languages.json`. اختبارات `test_locales.py` تتحقق من اكتمال المفاتيح.

## النشر
`deploy/Dockerfile` و`render.yaml`. ملاحظة: الحسابات والبيانات تحتاج قرصًا دائمًا (SMM_DB). قد تتطلب الاستضافة الدائمة حسابًا وبيانات دفع، ولن أنفّذ ذلك بدون موافقتك.
